## 安装

从本 Release 的 Assets 下载 `dmusic-v1.2.23.apk`，然后执行：

```bash
adb install -r dmusic-v1.2.23.apk
```

签名与上一版一致，可直接覆盖安装并保留歌曲、歌单、下载记录和播放断点。不同签名的安装包不能直接覆盖，需要先卸载。

## 本次更新

### 后台播放

- 后台播放迁移到 `audio_service`，由音频服务管理共享 FlutterEngine。
- 通知栏、锁屏、蓝牙媒体按键和 4x2 桌面小组件统一使用同一个 MediaSession。
- 保留原有解码、队列、缓存、断点续播和歌单顺序播放逻辑。

### 桌面小组件

- 正常暂停、应用内返回退出时立即更新为播放三角（▶）。
- 播放中从多任务划掉应用后，小组件最多约 2 秒复位为播放三角，不依赖应用在进程结束后继续执行。
- 增加 Activity finishing 原生收尾、冷启动关闭握手和 generation 校验，避免旧退出回调停止新播放。
- 组件尺寸变化时重新核验状态，旧进程快照不会恢复为播放态。

## 已知限制

- 部分定制 Android 系统会在划掉任务时直接结束应用进程，不保证投递 `onTaskRemoved` 或执行 `Activity.onDestroy`。因此 2 秒是小组件侧软超时，不承诺所有 ROM、所有清理方式都严格准时。
- 移动或重设桌面组件时，启动器可能重新应用缓存视图，导致复位动画短暂重放；应用随后会重新核验并压回播放三角。
- 系统设置中的“强行停止”会取消应用调度，Android 15 起还可能禁用桌面组件，应用不会绕过该行为。
- 第三方音源可能失效或限流，无法保证所有歌曲始终可播放。
